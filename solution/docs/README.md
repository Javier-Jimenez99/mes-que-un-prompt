# 📚 Technical Documentation & Research Notes

This directory houses technical design documents, experiment logs, and the draft for the official competition report.

---

## Documentation Index

* **Design Records:** Technical trade-offs, spatial feature rationale, and model decision criteria.
* **Experiment Log:** Historical benchmark runs on `evaluation/run_evaluation.py` tracking `spellF1`, `macroF1`, possession counts, and mean durations.
* **Competition Deliverable:** Final technical submission document conforming to [SUBMISSION.md](../../SUBMISSION.md), addressing:
  1. Methodological approach and architectural decisions.
  2. Assets utilized and lessons learned from discarded approaches.
  3. Possession and dead-ball transition heuristics.
  4. Known failure modes and limitations.
  5. Exact step-by-step reproduction instructions.
